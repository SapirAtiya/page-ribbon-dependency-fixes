# SDK distribution preparation

This repository contains reviewed prebuilt distribution JavaScript, declarations and maps, not the full upstream SDK workspace. The source patch applies to public Cloudflare workers-sdk commit 540f0844667abacb36dee94c078d403192bab1bd and incorporates Undici commit 7507102a675b082a71437f0a00681e537875556c (7.30.1).

The local input archives are identified by SHA-256 in UPSTREAM.json. No SDK or Node rebuild is performed. Generic virtual paths replace private diagnostic paths at the same UTF-16 width and newline positions. Syntax-tree and token checks permit changes only to internal module/function labels, comments, the recursively checked embedded proxy worker and the exact declared Wrangler fork-version literal. All other program tokens and token positions remain unchanged. Source-map mappings, arrays and embedded source content are retained, with the same path/version substitutions. The public versions retain the full page-ribbon.undici.1 suffix so their length matches the original private version; only the separator changes from plus to hyphen.

Package metadata is scoped honestly and development-only source-workspace commands/dependencies are omitted from the prebuilt distributions; upstream test sources/assertions are not edited. Runtime dependencies remain, with the exact matching Wrangler fork alias. Cloudflare MIT/Apache and Undici license texts are included. THIRD_PARTY_LICENSES.txt retains mapped dependencies' available license texts, original attribution/manifests and README notices, including the PSF notice and change history for the bundled difflib port. The difflib algorithm is unchanged; only surrounding SDK diagnostic labels are sanitized. This file records a distribution preparation, not a new upstream-source build or a legal certification.

The private input tree, private cache prefixes, app source/history and local evidence are outside this export. The root remains private and both publication plans remain disabled. The six distribution manifests have public-ready metadata; the reviewed publisher still rejects unapproved publication, unverified ownership/identity/authentication and incorrect workflow credentials.
