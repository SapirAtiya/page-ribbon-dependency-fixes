# @page-and-ribbon/glob-sync

Local publication review snapshot; publishing is blocked by private:true. Not an official upstream release.

Bounded synchronous file discovery for two maintained dependency forks.

Owned adapter for the two named synchronous consumers; it is not a general Fast-glob compatibility API. FAST_GLOB_LICENSE retains scheduling/pruning attribution.

Upstream origins, exact file differences and hashes are recorded in the source repository UPSTREAM.json. No application code or customer content is part of this package.

Requires Node >=22.13.0; local verification uses Node 24.19.0. It is not registry-authenticated before an approved real publication.
